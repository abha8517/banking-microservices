# Banking Microservices (Skeleton)

This repository is a generated skeleton for a Java + Spring Boot microservices banking backend.
It contains multiple Maven modules (common, config-server, discovery-server, gateway, auth-service,
person-service, account-service, transaction-service, cards-service, notification-service, statement-service).

This is a blueprint/skeleton: many files are minimal and use placeholders. Use this as a starting point.

## Quickstart (dev)
- Build: `mvn -T 1C clean package -DskipTests`
- Start dev stack (example): `docker compose up --build` (file included but services are minimal)
